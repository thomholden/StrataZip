New in 1.2

An archive you keep working in

Not only written once: a 1.2 archive can be mounted, synced, locked, signed and searched, and every change is a commit you can go back to. Six jobs it does, each walked through with real output in the guide. Locks and signatures are new in 1.2 and not yet reviewed outside the project; SECURITY.md says what they protect and what they do not.

Years of data, small

Sensor readings, prices and logs, coded by a model that knows which column each byte sits in. One file comes back out without unpacking the rest.

$ stratazip -l 9 -c logs logs.stz$ stratazip --get logs.stz day-17.log out.log

A backup you can check

Recovery records mend a bad sector, a signature shows it is unchanged since you signed it, and every night is a commit you can go back to.

$ stratazip -r 5 -c work backup.stz --sign-with me.key$ stratazip --sync work backup.stz$ stratazip --at 2026-11-24T23:00 -d backup.stz old
See it run →

An archive as a drive

Mount it and work in it like any folder. Each change is a commit; a crash costs only what was written since the last one. Lock a folder, even while mounted.

$ stratazip --mount office.stz ~/office --rw$ stratazip --seal office.stz hr --lock hr -p
See it run →

Two machines in step

One archive keeps folders on several machines in step, over ssh if you like. Text edits merge; a real conflict keeps both versions.

$ stratazip --sync ~/notes ssh://nas/notes.stz --two-way
See it run →

Search without unpacking

An index of the words, kept current by every commit. Rank the files without decoding them, or hand a language model the passages that answer.

$ stratazip -c docs docs.stz --index$ stratazip --search "refund policy" docs.stz --passages
See it run →

When a disk goes bad

Damage is found, never decoded into wrong bytes. With recovery records it is mended; without, every file that can be proved whole is kept.

$ stratazip -v backup.stz$ stratazip --repair backup.stz mended.stz

Why it comes out smaller

Nothing is guessed from a file name. Each block goes to whichever coder measures smallest on that block.

The right coder per block

Text, code and tables go to a context-mixing model with forty contexts; 16-bit images to a picture coder that finds their width itself; 16-bit audio to a waveform coder; DNA to a two-bit coder that learns both strands; ZIP and PDF contents are unwrapped first.

Verified, and repairable

A CRC-32 on every block and a SHA-256 on every file. A damaged archive is refused, never silently mis-decoded, and optional Reed-Solomon recovery records (-r 5) can repair it.

Whole trees, incrementally

Permissions, times and links kept; identical files stored once. Give it last night's archive with --from and unchanged files are not even read again.

One file out of many

--get decodes only the blocks that hold the file you asked for.

Safe writes

Output goes to a temporary name and is renamed into place only when it is complete.

Readable forever

Every .stz archive StrataZip has written stays readable by every later version. The format is documented in full.

Install

Ubuntu and Kubuntu 24.04 or 26.04: download the .deb from the latest release. Every release is installed and tested on both before it is published. Other x86-64 Linux: use the .tar.gz, or build from source with Qt 6.4 and CMake.

$ sudo apt install ./stratazip_*.deb
$ stratazip --test
