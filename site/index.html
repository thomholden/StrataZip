StrataZip

The smallest archives of the tools we tested, on the standard corpus and on structured data.

CSV, logs, sensor and market data, audio and genomes: StrataZip tries several coders on every block, keeps the one that wins, and checks every byte on the way out. The smallest of the tools we tested on the mixed files of the Silesia corpus too, with verification and repair built in.

The honest part: levels 9 and 10 are slow, and as slow to open as to make, like zpaq and cmix; zpaq -m5 compresses about five times as fast as level 9 and decompresses about four times as fast. They are for archives you keep. On enwik8 zpaq -m5 beats level 9 by 1.6%; level 10 is the figure above. The research compressors cmix and paq8px publish smaller results on these corpora; they were not run here. The Bitcoin file is private and available on request to anyone who wants to check the result. Full tables, the machine and every caveat: BENCHMARKS.md.

Why it comes out smaller

Nothing is guessed from a file name. Each block goes to whichever coder measures smallest on that block.

The right coder per block

Text, code and tables go to a context-mixing model with forty contexts; 16-bit images to a picture coder that finds their width itself; 16-bit audio to a waveform coder; DNA to a two-bit coder that learns both strands; ZIP and PDF contents are unwrapped first.

Verified, and repairable

A CRC-32 on every block and a SHA-256 on every file. A damaged archive is refused, never silently mis-decoded, and optional Reed-Solomon recovery records (-r 5) can repair it.

Whole trees, incrementally

Permissions, times and links kept; identical files stored once. Give it last night's archive with --from and unchanged files are not even read again.

One file out of many

--get decodes only the blocks that hold the file you asked for.

Safe writes

Output goes to a temporary name and is renamed into place only when it is complete.

Readable forever

Every .stz archive StrataZip has written stays readable by every later version. The format is documented in full.

Install

Ubuntu and Kubuntu 24.04 or 26.04: download the .deb from the latest release. Every release is installed and tested on both before it is published. Other x86-64 Linux: use the .tar.gz, or build from source with Qt 6.4 and CMake.

$ sudo apt install ./stratazip_*.deb
$ stratazip --test
